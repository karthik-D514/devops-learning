# Linux find Command - Complete Beginner-to-Advanced Guide

## Overview

The `find` command is one of the most powerful, versatile, and heavily used command-line tools in Linux. Unlike `locate` (which searches a pre-built index database that may be outdated), `find` crawls the live filesystem in real-time.

---

# 1. The Golden Formula of `find`

Every `find` command follows this fundamental syntax:

```bash
find  [WHERE_TO_SEARCH]  [CRITERIA]  [ACTION]
```

- **`WHERE_TO_SEARCH`**: The directory to start crawling (e.g. `/var/log`, `/etc`, `.`). Defaults to current directory `.` if omitted.
- **`CRITERIA`**: Name, size, file type, permissions, modification time, ownership, etc.
- **`ACTION`**: What to do with matching files. Defaults to `-print` (print to terminal) if omitted.

---

# 2. Finding by Name & Filename Patterns

| Option | Behavior | Example |
| :--- | :--- | :--- |
| **`-name`** | Exact **case-sensitive** match | `find /var/log -name "*.log"` |
| **`-iname`** | **Case-insensitive** match | `find /etc -iname "*nginx*"` |

> ⚠️ **Golden Rule on Wildcards:**
> Always enclose wildcard patterns inside quotes (`"*.log"`). If you run `find / -name *.log` without quotes, the bash shell will expand `*.log` into matching files in your current directory before `find` even runs, leading to strange errors!

---

# 3. Finding by File Type (`-type`)

In Linux, "everything is a file". Use `-type` to filter specific object types:

| Type Code | File Object Type | Example |
| :---: | :--- | :--- |
| **`f`** | Regular file (text, binary, script, image) | `find /opt -type f` |
| **`d`** | Directory | `find /var -type d -name "log*"` |
| **`l`** | Symbolic link (symlink) | `find /etc -type l` |
| **`s`** | Socket file (used for inter-process communication) | `find /run -type s` |

---

# 4. Finding by File Size (`-size`)

Essential for troubleshooting disk space alerts when `/` or `/var` reaches 100%:

### Size Units:
- `c` = bytes
- `k` = kilobytes
- `M` = megabytes
- `G` = gigabytes

### Prefix Signs:
- **`+`** = **GREATER than**
- **`-`** = **LESS than**
- *(no sign)* = Exactly that size

```bash
# Find files LARGER than 100 Megabytes:
find /var -type f -size +100M

# Find files SMALLER than 50 Kilobytes:
find /etc -type f -size -50k

# Find completely empty files (0 bytes):
find /tmp -type f -empty
```

---

# 5. Finding by Time (`-mtime`, `-mmin`)

Linux tracks three distinct timestamps for every file:
- **`mtime`** (Modified Time): When the file **content** was last changed.
- **`atime`** (Access Time): When the file was last **read**.
- **`ctime`** (Change Time): When file **metadata/permissions** were last changed.

### Days vs. Minutes:
- **`-mtime`** = Time measured in **24-hour days**.
- **`-mmin`** = Time measured in **Minutes**.

### The `+` vs. `-` Rule (The Classic Trap):
| Syntax | Meaning | Real-World Use Case |
| :--- | :--- | :--- |
| **`-mtime -7`** | Modified **LESS than 7 days ago** | "Recent files created this week" |
| **`-mtime +30`** | Modified **MORE than 30 days ago** | "Old logs ready to be deleted/archived" |
| **`-mmin -60`** | Modified **LESS than 60 minutes ago** | "What changed in the last hour during the incident?" |

```bash
# Find log files modified more than 30 days ago:
find /var/log -type f -name "*.log" -mtime +30

# Find configuration files in /etc edited in the last 24 hours:
find /etc -type f -mtime -1
```

---

# 6. Finding by Permissions (`-perm`)

This connects directly to security auditing and special permissions (SUID/SGID):

### Exact Match vs. Bitmask Match (`-` sign):
- **`-perm 644`** (no sign): Matches files whose **exact and only permissions** are `644` (`rw-r--r--`).
- **`-perm -4000`** (with minus): Matches files that have **AT LEAST the SUID bit set** (e.g. `4755` or `4711`).
- **`-perm -2000`** (with minus): Matches files that have **AT LEAST the SGID bit set**.

```bash
# Security Audit: Find all SUID executables across the entire system:
find / -type f -perm -4000 2>/dev/null

# Find world-writable files (security hazard):
find /var/www -type f -perm -002 2>/dev/null
```

---

# 7. Finding by Ownership (`-user`, `-group`)

```bash
# Find all files owned by user 'nginx':
find /var -user nginx

# Find orphaned files whose owning user was deleted from the system:
find /home -nouser
find /data -nogroup
```

---

# 8. Taking Action on Found Files (`-exec` and `-delete`)

Finding files is only half the battle; executing operations on them is where automation begins.

### Method 1: `-delete` (Direct Deletion)
```bash
# Delete all .tmp files in /var/tmp:
find /var/tmp -type f -name "*.tmp" -delete
```
> ⚠️ **Safety Tip:** Always run the `find` command **without** `-delete` first to preview the exact list of files before deleting them!

### Method 2: `-exec` (Execute Custom Command)
The `-exec` flag runs a command on every file found.

**The Syntax:**
```bash
find ... -exec COMMAND {} \;
```
- **`{}`** = Placeholder automatically replaced by each matching file path.
- **`\;`** = Required ending delimiter indicating the end of the command.

```bash
# 1. Find all shell scripts and make them executable:
find /opt/scripts -type f -name "*.sh" -exec chmod +x {} \;

# 2. Find log files older than 90 days and compress them with gzip:
find /var/log/archive -type f -name "*.log" -mtime +90 -exec gzip {} \;

# 3. Find files owned by 'nobody' and list detailed information:
find /tmp -user nobody -exec ls -lh {} \;
```

---

# 9. Top DevOps / SRE Production Cheat Sheet

```bash
# 1. Clean up old logs to free disk space:
find /var/log/myapp -type f -name "*.log" -mtime +30 -delete

# 2. Find massive files eating up disk:
find / -type f -size +500M -exec ls -lh {} \; 2>/dev/null

# 3. Find all files modified in the last 15 minutes during an incident:
find /etc /var/www -type f -mmin -15

# 4. Security scan for rogue SUID files:
find / -perm -4000 -type f 2>/dev/null

# 5. Fix web directory permissions (directories 755, files 644):
find /var/www/html -type d -exec chmod 755 {} \;
find /var/www/html -type f -exec chmod 644 {} \;
```
